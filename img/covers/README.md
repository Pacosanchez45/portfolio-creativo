# Project covers

Six thematic editorial covers generated with the built-in image generation tool, then exported as JPEG for web delivery. These are conceptual illustrations, not screenshots of the websites. Existing screenshots remain in the case studies.

## dental.jpg

Use case: product-mockup. Create a polished editorial project cover for a dental clinic website portfolio. Landscape 3:2 composition. A sculptural matte ivory tooth model on a pale mint plinth in a beautiful contemporary dental clinic, soft blurred dental chair and curved architecture in background, small brushed chrome dental mirror neatly placed in foreground, warm daylight, muted teal and ivory palette, premium architectural/product photography, believable materials, calm trustworthy sophisticated visual. Main subject in central 65% so crop to 16:10 safely. No text, no logos, no watermark, no collage.

## uxsignal.jpg

Use case: stylized-concept. Create a premium editorial cover for UXSignal, an AI-assisted UX research software project. Landscape 3:2. A beautifully crafted arrangement of frosted translucent glass panels suggesting research interview notes, connected by fine teal threads to one glowing insight node, on a dark graphite studio background. Restrained mint and electric blue accents, precise physical materials, soft cinematic light, high-end 3D product visualization, coherent and spacious, not busy. Abstract cards have only simple subtle lines, no readable text. Central 65% safe for crop to 16:10. No logos, no watermark.

## uiverse.jpg

No words, no logos, no watermark.

Premium macro studio product photography/3D, elegant and restrained. Center-weighted arrangement safe to crop to 16:10, no keyboard, no letters, no text, no logos, no watermark.
